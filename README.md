# Estoque de Switches

Sistema web para gerenciamento de estoque de switches de rede.

Este projeto foi desenvolvido como **Projeto de Integração DevOps**, com o objetivo de demonstrar conhecimentos em:

- Desenvolvimento Back-end com Flask
- Desenvolvimento Front-end com React (Vite)
- Integração com banco de dados MySQL/MariaDB
- Criação de API REST
- Autenticação básica
- Versionamento e documentação seguindo boas práticas

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React + Vite
- **Back-end:** Python + Flask
- **Banco de Dados:** MySQL / MariaDB
- **Controle de Versão:** Git e GitHub
